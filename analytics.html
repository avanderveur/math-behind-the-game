Final Mathematical Explanation

Why This Is Differential Calculus

This project is about change. A pitch changes position over time, a batted ball changes height over time, and derivatives describe those changes.

Core Equations

x(t) = v₀cos(θ)t

y(t) = y₀ + v₀sin(θ)t − 16t²

x′(t) = v₀cos(θ)

y′(t) = v₀sin(θ) − 32t

maximum height occurs when y′(t) = 0

Baseball translation

The position functions tell where the ball is. The derivative tells how fast the ball is moving and in what direction. This is why velocity vectors matter in baseball analytics.

Pitching uses this idea to study how quickly a pitch reaches the plate. Hitting uses it to study how the ball leaves the bat. Spray charts show where that motion finishes on the field.
